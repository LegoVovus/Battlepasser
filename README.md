# Battlepasser — all-in-one script which automates most of things on Rugplay
## Easy start
- Set the config.py up
  - Provide the Rugplay domain
  - Paste your Better Auth Session Token
- Open your favourite or needed module! All extra information you'll see there
## Modules
In Battlepasser there are such modules as:
- Autotrade — trading a coin
- Gambler — playing arcades (coinflip/slots)
- Cloud9 — for "Cloud9" achievement
- 24mines — playing with 24 mines
- Coin Creator — creating coins for you with 120sec delay
- Hopium — bets on a hopium
- Commenter — commenting under a coin
> On [catplay](catplay.org) there's a delay for creating coins (1 per 2min; 5 per hour; 10 per day).
